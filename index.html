About this application

This application is a personal, non-commercial OAuth client ID and client secret created for the Google Drive API. It is used together with rclone, an open-source command-line program for managing cloud storage, to synchronize, back up and restore files in a single Google Drive account owned by the developer.

It is not a public service and is not offered to third parties. There is no hosted backend, no account system and no analytics. All authentication and data transfer happens directly between the user's own device and Google's servers.

What it does

  • Connects to the Google Drive account explicitly authorized by its owner.
  • Synchronizes, backs up and restores files selected by the user.
  • Stores OAuth tokens locally on the user's own device.

See the Privacy Policy for a full description of what data is accessed and how it is handled.
